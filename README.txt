KURT MOTOSHOP V.1

PHONE-ONLY BUILD:
1. Upload the contents of this ZIP to your GitHub repository. Easiest: upload the project folder files plus .github folder.
2. Open Actions.
3. Select "Build KURT MOTOSHOP V1".
4. Tap Run workflow.
5. When Success, open the workflow run and download the KURT-MOTOSHOP-V1-APK artifact.
6. Extract the artifact ZIP and install app-debug.apk.

The app is offline-first and stores inventory locally.
